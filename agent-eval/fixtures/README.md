# Fixtures

Files the `casefile` suite (`cases/casefile.yaml`) uploads as the user's own documents, one folder
per case file. They are invented: the parties, the addresses and the letters do not exist.

`tenancy-retaliation/` - a Zurich tenancy. The decisive facts sit deep inside the files:
the tenant's request for a rent reduction is the fourth of six e-mails in `Mailverkehr_Schimmel.txt`,
and the notice period is Art. 19 of `Mietvertrag_Hornbachstrasse.txt`, a 12,500-character lease padded
with standard clauses. Together the four files exceed what the agent is shown whole (12,000
characters), so Case Prep has to find them in the matter's search index.
